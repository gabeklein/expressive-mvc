A bare `Component` given `for` provides one State to its children in any host: `<Component for={Session} name="Ada">`. A class is constructed and owned by the element, receives `is`, and its `mount()` runs with the element's. An active instance is provided as-is, never destroyed. Other attributes assign to the provided State on every render. Changing `for` releases the previous item first. In `for` mode there is no default suspense boundary unless `fallback` or `catch` is passed.
