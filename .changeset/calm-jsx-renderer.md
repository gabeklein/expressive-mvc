Add a browser-ready MVC-native JSX renderer with function and class components, context, native events, keyed reconciliation, direct reactive collections, portals, lazy components, error/suspense boundaries, and committed-content retention while `pending()` work suspends. Alternate hosts can reuse its state and render-scope lifecycle from `@expressive/jsx/adapter` without registering DOM element mechanics.
