title: React Hooks
description: Model.get and providing context for function components
---

The React adapter augments the `Model` class with a static hook, `Model.get()` - function components read state that a Component owns or an element provides. Function components own nothing; owned state lives on a [`Component`](/docs/api/component) or is placed with `<Component for>`. Import the adapter once, for its side effect, in your app's entry; everything else imports from `@expressive/mvc`.

```tsx
import '@expressive/react';
import { Model, Component } from '@expressive/mvc';
```

<br />

## `Model.get()`

Fetches an instance from context and subscribes to accessed properties.

```tsx
function Profile() {
  const { user } = UserProfile.get();
  return <h1>{user.name}</h1>;
}
```

- Throws `Could not find UserProfile in context.` if the instance is not provided above.
- Re-subscribes (and refreshes) if the upstream instance is replaced.

### Optional lookup

```tsx
const maybe = Theme.get(false); // Theme | undefined
```

### Required values

```tsx
const user = User.get(true); // Required<User>
```

With `true`, reading a property that is currently `undefined` throws a plain `Error` - `User-XXXXXX.name is required in this context.` That surfaces at the nearest **error boundary**, not Suspense. Use it when the component's contract is "this data exists by now."

### Computed selector

Pass a factory to derive a value. The component re-renders only when the derived result changes by `===`:

```tsx
const summary = Cart.get((cart) => ({
  total: cart.total,
  count: cart.count
}));
```

The factory receives:

- A tracking proxy (reads subscribe).
- A `ForceRefresh` function.

### Effect mode

Return `null` from the factory to run a side effect once, on first render, without subscribing - the factory doesn't run again:

```tsx
AppState.get((app) => {
  analytics.track('page', app.page);
  return null;
});
```

### `ForceRefresh`

The second argument is a function that forces the component to re-render:

```ts
type ForceRefresh = {
  (): void;
  <T>(waitFor: Promise<T>): Promise<T>;
  <T>(invoke: () => Promise<T>): Promise<T>;
};
```

```tsx
const data = DataService.get((svc, refresh) => {
  const reload = () => refresh(svc.fetch());
  return { items: svc.items, reload };
});
```

Given a promise (or async function), it refreshes now and again when the promise settles.

## Providing context

Hooks read what an ancestor provides. Provide an instance with the bare `Component` class:

```tsx
<Component for={Theme} color="dark">
  <App />
</Component>
```

- A class is constructed and owned by the element, destroyed on unmount; `is` receives it.
- An instance someone else owns - a Component's field, a module-scope `Model.new()` - is provided as-is and never destroyed by the element.
- Other attributes are typed from the instance and assigned to it on every render.
- `fallback` adds a Suspense boundary and `catch` an error boundary; without them it adds none.
- One instance per element - several belong to a parent instance owning them as fields.

`Provider` was removed in favor of `<Component for>`. Its record form (`for={{ theme: Theme, auth: Auth }}`) has no equivalent - compose a parent `Model` class instead. Details in the [Context guide](/docs/guides/context#providing-with-component-for).

<br />

## Reading context inline

`Consumer` was removed. Read context with `Model.get()` in a small function component:

```tsx
const Themed = () => {
  const theme = Theme.get();
  return <p style={{ color: theme.color }}>Themed</p>;
};
```
