description: TypeScript type aliases on the Model namespace
---

Most public types are namespaced on `Model`; component prop types are namespaced on `Component`. Import them from `@expressive/mvc`:

```ts
import type { Model } from '@expressive/mvc';
```

<br />

## Class shape

### `Model.Extends<T>`

Abstract or concrete constructor of a Model. Use for parameters that accept any class in the hierarchy.

```ts
function lookup<T extends Model>(Type: Model.Extends<T>): T | undefined;
```

### `Model.Type<T>`

Concrete (instantiable) constructor. Use when `new` is required.

```ts
function create<T extends Model>(Type: Model.Type<T>): T;
```

<br />

## Field introspection

### `Model.Property<T>`

Keys of `T` excluding inherited `Model` members (`get`, `set`, `is`, etc.). This includes [unmanaged](/docs/guides/state-classes#unmanaged-properties) `_` keys, so it's the key set for overlays like `Model.Assign<T>` and component props.

### `Model.Field<T>`

Managed keys only - `Model.Property<T>` without `_` keys. Snapshots (`Model.Values<T>`), `ref` proxies and instruction keys use this.

```ts
class MyModel extends Model {
  foo = 1;
  bar = 'hello';
  _handle = null;
}

type Properties = Model.Property<MyModel>; // 'foo' | 'bar' | '_handle'
type Fields = Model.Field<MyModel>; // 'foo' | 'bar'
```

### `Model.Event<T>`

Any valid event key - includes fields, numbers, symbols, and arbitrary strings for custom events.

```ts
type Event<T> = Field<T> | number | symbol | (string & {});
```

### `Model.Signal<T>`

All event signals dispatched to listeners, including lifecycle meta events.

```ts
type Signal<T> = Event<T> | true | false | null;
```

Meaning of special values:

- `true` - initial activation (ready)
- `false` - a normal update flush completed
- `null` - destruction

<br />

## Values and snapshots

### `Model.Values<T>`

All fields with exotic values (child states, refs, etc.) unwrapped to their inner type.

```ts
type Values<T> = { [P in Field<T>]: Export<T[P]> };
```

### `Model.Partial<T>`

Object compatible with `Values<T>` - every key optional, Export-unwrapped.

```ts
type Partial<T> = { [P in Field<T>]?: Export<T[P]> };
```

Not currently used by any public signature - `set(assign)` takes [`Model.Assign<T>`](#modelassignt), which preserves declared field types rather than unwrapping them.

### `Model.Value<T, K>`

Single-property lookup type with `Export<>` unwrapping.

### `Model.Export<R>`

If `R` is itself a Model, recursively exports `Values<R>`. Otherwise, if `R` has a `.get(): T` method, extracts `T`. Otherwise returns `R`. Drives child-state and ref unwrapping in snapshots.

```ts
type Export<R> = R extends Model
  ? Values<R>
  : R extends { get(): infer T }
  ? T
  : R;
```

## Constructor args

### `Model.Args<T>`

Union type accepted by `Model.new()` and `Model.use()`:

```ts
type Args<T> = (Args<T> | Init<T> | Assign<T> | void)[];
```

Arrays are flattened recursively at runtime.

### `Model.Init<T>`

A lifecycle callback passed to `Model.new()`. Can return cleanup, object (assign), or array (recurse).

```ts
type Init<T> = (
  this: T,
  thisArg: T
) => Promise<void> | (() => void) | Args<T> | Assign<T> | void;
```

### `Model.On<T>`

Handler object accepted by `Model.on()` - hooks lifecycle by stage.

```ts
interface On<T> {
  type?(type: Model.Extends<T>): void;
  pre?(this: T, self: T): void | (() => void) | Promise<void> | Args<T> | Assign<T>;
  new?(this: T, self: T): void | (() => void);
  bind?(this: T, key: string, fn: Function, self: T): void;
  catch?(
    this: T,
    error: unknown,
    kind: 'effect' | 'getter' | 'setup' | 'dead' | 'unused',
    key?: string
  ): unknown;
}
```

Stage timing is covered under [`Model.on`](/docs/api/state#modelonhandler); `catch` kinds under [Error handling](/docs/api/state#error-handling).

### `Model.Global<T>`

Value of `static global`. A boolean opts a class in or out of the global root; a resolver decides per instance at activation.

```ts
type Global<T> = boolean | ((self: T) => boolean);
```

A bare literal (`static readonly global = true`) seals the choice for subclasses - widen a subclass's `static global` to `Model.Global` to allow a resolver or a later override. See [root context and globals](/docs/api/utilities#root-context-and-globals).

### `Model.Assign<T>`

Object overlay type. Maps each field to its value type, preserving method `this`.

```ts
type Assign<T> = Record<string, unknown> & {
  [K in Property<T>]?: T[K] extends (...args: infer A) => infer R
    ? (this: T, ...args: A) => R
    : T[K];
};
```

> The `Record<string, unknown>` intersection means unknown keys pass the type-checker (they're ignored at runtime) - value-correctness of declared fields is the only check. See [What `Assign` checks](/docs/api/state#what-assign-checks).

## Callbacks

### `Model.OnEvent<T>`

```ts
type OnEvent<T> = (
  this: T,
  key: Signal<T>,
  source: T
) => void | (() => void) | null;
```

Return a function for a deduped settle callback. Return `null` to auto-unsubscribe.

### `Model.Effect<T>`

```ts
type Effect<T, R = EffectCallback | Promise<void> | null | void> = (
  this: T,
  current: T,
  update: readonly Event<T>[] | undefined
) => R;

type EffectCallback = (update: boolean | null) => void;
```

### `Model.Release<R>`

```ts
type Release<R = void> = (() => void) & PromiseLike<R>;
```

Returned by `get(effect)`. Call to stop the effect; await to stop it once it settles and receive the latest run's value. A sync effect returns its cleanup, so only an async effect resolves a value.

### `Model.Setter<T>`

```ts
type Setter<T> = (value: T, previous: T) => T | void;
```

<br />

## Descriptors

### `Model.Apply<T>`

Property descriptor config for `set(key, config)` and `def` factories:

```ts
type Apply<T> = {
  value?: T;
  get?: ((source: Model) => T) | boolean;
  set?: Setter<T> | boolean;
  enumerable?: boolean;
};
```

### `Model.Define<T, K>`

Type-safe variant of `Apply` used by `set(key, config)` - enforces `T[K]` when `K` is a known field.

<br />

## Updated

### `Model.Updated<T>`

```ts
type Updated<T> = readonly Event<T>[] & PromiseLike<readonly Event<T>[]>;
```

Returned by `set()` - a synchronously readable array of keys updated, awaitable to wait for batch settlement.

<br />

## Refs

### `ref.Object<T>`

```ts
interface ref.Object<T> {
  (value: T | null): void;
  current: T;
  is: Model;
  key: string;
  get(): T | null;
  get(callback: (v: T) => void): () => void;
}
```

### `ref.Proxy<T>` and `ref.CustomProxy<T, R>`

Produced by `ref(this)` and `ref(this, mapFn)` respectively.

```ts
type ref.Proxy<T extends Model> =
  { [P in Model.Field<T>]-?: ref.Object<T[P]> } & { get(): T };

type ref.CustomProxy<T extends Model, R> =
  { [P in Model.Field<T>]-?: R } & { get(): T };
```

<br />

## Component

### `Component.Props<T>`

The full JSX prop type for a `Component` subclass. Combines:

- Model fields (optional)
- `render(props)` declared props (optional or required as declared), or `children` when `render` declares none
- `is`, `fallback` and `catch` special props
